# 📘 PISA Жас дарын — оқу платформасы (Streamlit)

Stepik-ке ұқсас оқу платформасы: курс → модуль → сабақ → қадам (тапсырма), мұғалім редакторы,
сыныптар, оқушыларды email арқылы тіркеу, автоматты тексеру және журнал.

## Мүмкіндіктер

**Мұғалім**
- 📚 **Курстар** — курс, модуль, сабақ құру; сабақ ішінде Stepik-тегідей «➕ Жаңа қадам»:
  | Түрі | Тексерілуі |
  |---|---|
  | 📄 Мәтін (теория, PISA мәтіндері, суреттер, кестелер) | — |
  | ☑️ Тест (бір / бірнеше жауап, араластыру) | авто |
  | ▦ Кестелік (Иә/Жоқ, Верно/Неверно — PISA стилі) | авто, жартылай балл |
  | 🔢 Сандық (рұқсат етілген қателікпен) | авто |
  | 🔤 Мәтіндік жауап (бірнеше дұрыс нұсқа, regex) | авто |
  | ✏️ Бос орындарды толтыру `[[жауап\|балама]]` | авто, жартылай балл |
  | 🔗 Сәйкестендіру | авто, жартылай балл |
  | ↕️ Ретке келтіру | авто, жартылай балл |
  | 📝 Еркін жауап | мұғалім қолмен бағалайды |
  Әр қадамға: балл, әрекет саны, жартылай балл, түсіндірме, алдын ала қарау, суретті жүктеу.
- 👥 **Сыныптар** — сынып құру → **сынып сілтемесі** (`https://.../?join=КОД`) және код.
  Оқушыларды тізіммен қосу, құпиясөзді жаңарту, тіркелуді жабу.
- 📒 **Журнал** — оқушы × сабақ (немесе × әр тапсырма) кестесі, пайыз, CSV (Excel) жүктеу.
- 📝 **Тексеру** — еркін жауаптарға балл және пікір қою.
- ⬇ **Stepik импорт** — өз Stepik аккаунтыңызбен сабақтарды тарту.

**Оқушы**
- Сынып сілтемесін ашады → аты-жөні мен email жазады → **логин мен құпиясөз поштасына келеді**.
- Курс бағдарламасы (әр сабақ бойынша `балл / макс`), қадамдарды орындау, «Бағаларым».
- Әр жауаптан кейін балл автоматты түрде журналға жазылады (ең жоғары нәтиже есептеледі).

### 🏫 Мектеп кодтары (лицензия)
- **Әкімші** (`aidar` немесе `aidarpavl@gmail.com`, құпиясөзі Secrets-тегі `ADMIN_PASSWORD`) «🔐 Мектеп кодтары»
  бетінде мектеп атауын, оқу жылын және код санын таңдап, **6 таңбалы кодты автоматты жасайды**.
  Бұл бет басқа ешкімге көрінбейді; әкімші логиндерімен тіркелуге болмайды.
- Код **бір рет** қолданылады, оқу жылының соңына (31 тамыз) дейін жарамды — жыл сайын жаңа код беріледі.
  Барлық код деректер қорында сақталады; бұғаттауға/жоюға болады; CSV жүктеледі.
- Мұғалім «🏫 Мектеп» бетінде кодты енгізеді → мектеп атауы кодпен бірге жүктеліп, **беттің үстінде** тұрады.
- Код жоқ / мерзімі өткен болса — код **000000**: курстар ашылмайды, сынып құрылмайды, сабақ батырмалары
  белсенді емес (мұғалімге де, оның оқушыларына да). Қате кодты 15 минутта 5 реттен көп енгізуге болмайды.
- Мектеп пайдаланушысы сайтқа кірген сайын оның **IP-адресі** сол мектеп кодының жолындағы соңғы бағанға
  («IP-адрестер») жазылады (соңғы кіру уақыты және кіру саны).

### 👤 Профиль
Оқушы тіркеліп алғаш кіргенде профиль баптау беті ашылады: аты-жөні, сынып, литер, туған күні, телефон,
қала/ауыл, интерфейс тілі (кірген сайын сол тіл қосылады), құпиясөзді өзгерту.

### 🇰🇿/🇷🇺 Екі тіл
Барлық бет, мәзір, батырма, сабақ атаулары және тапсырмалар **қазақша және орысша**. Тілді сол жақ
панельдегі (немесе басты беттің жоғарғы оң жағындағы) ауыстырғыш өзгертеді. Мұғалім әр тапсырманы
редакторда «Мазмұн тілі: Қазақша / Русский» арқылы екі тілде толтырады.

### Дайын мазмұн (`content_data.py`)
Автордың Stepik сабақтарынан алынған 11 тапсырма — мәтіндер, кестелер, суреттер, дұрыс жауаптар:
- **1-нұсқа:** Витаминдер, Қаз ұшуы, Жер телімі, Ойын алаңы, Тістерді тазалау
- **2-нұсқа:** Күш, Тұздар, Жеке үй, Үй жоспары, Буэнос-Айрес, Әлемнің жаңа жеті кереметі
- **PISA 2009:** бос сабақтар (Stepik импорт немесе редактор арқылы толтырылады)

Мазмұн деректер қоры бос болғанда бір рет жазылады; кейін бәрін редакторда өзгертуге болады.

## 1. Компьютерде іске қосу

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # мәндерін толтырыңыз
streamlit run app.py
```
Ашылған бетте «👩‍🏫 Мұғалім ретінде тіркелу» → курс пен сынып құрасыз.

## 2. GitHub-қа салу

```bash
git init
git add .
git commit -m "PISA Жас дарын платформасы"
git branch -M main
git remote add origin https://github.com/<логин>/pisa-zhas-daryn.git
git push -u origin main
```
`secrets.toml` `.gitignore`-да тұр — құпиясөздер GitHub-қа кетпейді.

## 3. Streamlit Cloud-та веб-парақ ретінде жариялау

1. https://share.streamlit.io → **Create app** → GitHub репозиторийін таңдаңыз,
   Main file: `app.py`, Python: **3.12**.
2. **Advanced settings → Secrets** өрісіне `secrets.toml.example` мазмұнын өз мәндеріңізбен қойыңыз.
3. Deploy. Алынған адресті (`https://xxxx.streamlit.app`) `APP_URL`-ге жазып, қайта сақтаңыз —
   сынып сілтемелері осы адреспен жасалады.

### Деректер қоры (маңызды!)
Streamlit Cloud қосымша қайта іске қосылғанда жергілікті файлдарды өшіреді — SQLite журналы жоғалады.
Тұрақты сақтау үшін тегін PostgreSQL қосыңыз:
1. https://supabase.com (немесе https://neon.tech) → жаңа жоба.
2. Connection string (URI) көшіріп, Secrets-ке `DATABASE_URL = "postgresql://..."` деп қойыңыз.
Кестелер бірінші іске қосылғанда автоматты құрылады.

### Пошта (Gmail)
1. Мектептің Gmail аккаунтында **2-қадамдық тексеруді** қосыңыз.
2. https://myaccount.google.com/apppasswords → «App password» жасаңыз (16 таңба).
3. Secrets-тегі `[smtp]` бөліміне жазыңыз. Mail.ru: `smtp.mail.ru`, порт 465.
Пошта бапталмаса, құпиясөз оқушыға экранда көрсетіледі.

### Stepik импорт
1. https://stepik.org/oauth2/applications/ → New application:
   *Client type* — Confidential, *Authorization grant type* — Client credentials.
2. Client ID / Secret мәндерін «⬇ Stepik импорт» бетіне енгізіңіз (немесе Secrets-ке).
3. Сабақтарды белгілеп «Импорттау». Курс авторы болсаңыз дұрыс жауаптар да келеді;
   әйтпесе тек мәтін мен нұсқалар — дұрыс жауапты редакторда белгілейсіз.
